# Python Escape Room

A five-room terminal adventure built in Python. Each room has a different challenge to complete before the player can escape.

**Author:** Aqsa Shoaib  
**Original classroom project:** January 20, 2026

## Challenges

1. **Coin Flip:** Predict heads or tails.
2. **Rock Paper Scissors:** Beat the computer.
3. **Number Guess:** Find the secret number from 1 to 10 using hints.
4. **Trivia:** Answer three yes-or-no questions correctly.
5. **Dice Challenge:** Guess the result of a six-sided die.

## Run

Requires Python 3. No external packages are needed.

```bash
python escape_room.py
```

On systems that use `python3`, run `python3 escape_room.py` instead.

## Skills demonstrated

- Functions and control flow
- Loops and input validation
- Random number generation
- Dictionaries and tuples
- Organizing a game into reusable challenges

## Project history

This is a cleaned-up version of Aqsa's original five-room escape-room assignment. The revised version keeps the same challenges while fixing loops that could get stuck, validating player responses, and organizing game logic into separate functions.
